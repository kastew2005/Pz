# Важно: корректная публикация

Этот проект использует React + TypeScript + Vite. Нельзя публиковать исходный `index.html` напрямую через GitHub Pages: браузер не умеет запускать TSX-файл `src/main.tsx` как обычный JavaScript. Это приводит к вечному экрану «Загрузка игрового ядра».

В архив добавлен GitHub Actions workflow `.github/workflows/deploy.yml`: загрузите весь проект в репозиторий GitHub в ветку `main` или `master`, затем в Settings → Pages выберите **GitHub Actions** как источник. Workflow выполнит `npm ci`, `npm run build` и опубликует содержимое `dist`. В `vite.config.ts` включён относительный `base: "./"` для работы в подпапке репозитория.

# МЁРТВЫЙ ГОРОД — зомби-выживание (PWA)

Браузерная 2D-игра в духе Project Zomboid, адаптированная под телефоны. Вся графика и звук — процедурные (Canvas 2D + Web Audio API), внешние ассеты не нужны. Работает оффлайн как PWA.

## Запуск за 1 минуту

```bash
npm install
npm run dev        # разработка: http://localhost:5173
npm run build      # продакшн: dist/index.html (один самодостаточный файл)
npm run preview    # проверка продакшн-сборки
```

После `npm run build` папку `dist/` можно раздавать любым статическим сервером
(`npx serve dist`, GitHub Pages, nginx и т.д.). Service Worker (`sw.js`) закэширует
игру после первого визита — дальше она открывается без интернета. На телефоне:
«Добавить на главный экран» → полноэкранный режим.

## Управление

**Телефон:**
- Левый виртуальный стик — движение (до упора — бег)
- Кнопка кулака: тап — удар; удержание + свайп — прицел, отпускание — замах/выстрел
- Кнопка руки — контекстное действие (обыск/двери/окна/баррикады/сон); удержание — список всех действий
- Значок глаза — красться; нижняя панель — рюкзак, крафт, здоровье, фонарик, звук, меню

**ПК:** WASD — ходьба · Shift — бег · Ctrl — красться · ЛКМ — удар (удерж. — прицел) · ПКМ — толчок · E — действие · Q — меню действий · I/C/H — рюкзак/крафт/здоровье · F — фонарь · M — звук · Esc — пауза

## Механики (как в оригинале)

- Конус обзора (FOV) с тенями от стен/деревьев, память карты (туман войны), ночь/день, фонарики улиц, фонарик игрока
- Зомби слышат: шаги, выстрелы, разбитое стекло, сирены домов, вертолёт-событие
- Зоны тела: царапины, глубокие раны, кровотечения (бинт/тряпки), антисептик, обезбол, антибиотики; укус = инфекция Нокса (неизлечима)
- Голод, жажда, усталость (сон на кровати — перемотка времени), паника, боль, выносливость, перегруз, промокание под дождём и простуда (чихание = шум!)
- Лут: холодильники, шкафы, гаражи, магазины, аптеки, трупы; рюкзаки расширяют переносимый вес
- Крафт: порвать одежду на бинты, бита с гвоздями, баррикады окон (молоток + доски + гвозди), занавески на окна
- Нокдауны зомби и добивание лёжа; быстрые зомби встречаются редко; орды мигрируют на шум

## Структура проекта

```
index.html            — оболочка, PWA-мета, манифест
public/manifest.json  — манифест PWA
public/sw.js          — Service Worker (оффлайн-кэш)
src/game/consts.js    — константы, предметы, оружие, иконки SVG
src/game/world.js     — генерация города, LOS, коллизии, время, погода, лут-таблицы
src/game/zombies.js   — ИИ зомби (слух/зрение/орды/атаки/штурм дверей)
src/game/player.js    — статы, тело, инвентарь, бой
src/game/engine.js    — цикл, камера, рендер, FOV, свет, частицы
src/game/input.js     — джойстик, кнопки, клавиатура/мышь
src/game/ui.js        — HUD, мудлеты, инвентарь, крафт, здоровье, миникарта
src/game/audio.js     — Web Audio: шаги, стоны, удары, дождь, сирена, фортепиано ночи
src/game/game.js      — оркестратор, контекстные действия, события, смерть
```

Рекорд выживания хранится в localStorage.
