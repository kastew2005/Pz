# МЁРТВЫЙ ГОРОД — исправление публикации GitHub Pages

## Почему зависала загрузка

GitHub Pages отдавал исходный `index.html`, в котором указан `src/main.tsx`. Браузер не запускает TSX напрямую. Проект обязательно должен собраться Vite, и публиковать нужно содержимое `dist/`, а не исходники.

## Установка исправления

1. Распакуйте архив.
2. Загрузите **содержимое этой папки** в корень репозитория `kastew2005/Pz`, включая скрытую папку `.github` и файл `package-lock.json`. Не загружайте папку-обёртку `pzdiag`.
3. Сделайте commit в ветку `main` (workflow также слушает `master`).
4. В GitHub откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
5. Откройте **Actions → Deploy PWA to GitHub Pages**. Дождитесь, пока оба задания `build` и `deploy` станут зелёными.
6. Откройте `https://kastew2005.github.io/Pz/` и обновите страницу. Если старая версия ещё показывается, закройте старую вкладку и откройте сайт заново; при необходимости удалите данные сайта в настройках Safari.

## Важно

Не выбирайте `Deploy from a branch` для исходного React/Vite-проекта. При публикации исходников браузер снова попытается загрузить `src/main.tsx`, и игра не стартует. GitHub Actions запускает `npm ci`, `npm run build` и публикует готовую папку `dist`.

Локальный запуск (если есть Node.js): `npm ci`, затем `npm run build`. Готовый сайт появится в `dist/`.
